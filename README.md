# Russell Mutamba | Full-Stack Developer • Cloud & AI Engineer

A high-performance portfolio showcasing projects, skills, and experience in full-stack development, cloud architecture, and AI engineering. Built with a Jujutsu Kaisen (JJK) themed aesthetic.

## 🚀 Overview

This portfolio is a reflection of my journey as a software engineer. It combines a sleek, modern UI with deep technical integrations, demonstrating my expertise in bridging the gap between elegant frontend design and resilient backend systems.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, Motion (formerly Framer Motion)
- **3D/Graphics:** Three.js, React Three Fiber
- **Backend/Infrastructure:** Node.js, Firebase, AWS, Docker
- **AI Integration:** Google Gemini AI

## ✨ Key Features

- **Dynamic Theme:** Immersive Jujutsu Kaisen themed aesthetic with custom animations.
- **Project Showcase:** Detailed view of key projects with interactive components.
- **Experience Timeline:** A chronological look at my professional growth.
- **AI-Powered:** Integrated with Google's Gemini for enhanced interactivity.
- **Responsive Design:** Optimized for all screen sizes, from mobile to desktop.

## 🏁 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Create a `.env` file in the root directory and add your API keys (see `.env.example`):
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
